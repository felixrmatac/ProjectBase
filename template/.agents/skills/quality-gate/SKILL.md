# Quality Gate Skill

When activated, you must act as a strict orchestrator for the validation loop. 

## STEPS

1. **Estado VALIDATING**: Ensure the task in `docs/features/*/00-task.md` is updated to `status: VALIDATING`.

2. **Ejecuta el Script**: Run the deterministic quality gate script:
   `./scripts/quality-gate.sh`
   *(NOTE: The Agent only orchestrates; the script handles all validation logic deterministically.)*

3. **Evalúa Resultado**:
   - The script outputs a stable YAML contract containing `status: passed` or `status: failed`.
   - If `status: passed`, proceed to Step 4.
   - If `status: failed`, read the `failure.check` and `failure.error` fields. Fix the application code, and repeat Step 2.
   - The Agent MUST NOT interpret a failure as a pass, regardless of subjective reasoning.

4. **Registra Evidencia y Cierra (DONE)**:
   - Copy the exact output YAML from the successful `quality-gate.sh` execution.
   - Update `00-task.md`:
     - Change `status: DONE`.
     - Replace the `validation.quality_gate` block with the generated YAML output.
   - The Agent MUST NOT manually fabricate evidence that wasn't generated by the script.
   - Inform the user that validation is complete and the task is objectively DONE.
