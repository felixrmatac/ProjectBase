# PRD: Sistema UI Cognitivo para Estudio

## Criterios de Aceptación

- Todos los componentes deben estar escritos en Svelte 5 usando exclusivamente Runes (`$props`, `$state`, `$derived`). Prohibido `export let` o reactividad clásica (`$:`).
- Los estilos deben usar clases de Tailwind basadas en la paleta de ergonomía cognitiva.
- Cada componente debe contar con tests unitarios en Vitest.
