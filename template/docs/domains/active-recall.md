# Dominio: Active Recall y UI

## Componentes Requeridos

- **`StudyCard`**: Contenedor centrado de baja fatiga visual.
- **`RatingButton`**: Botón de calificación FSRS (1 a 4) con badge de atajo y variantes de color.
- **`ZenHeader`**: Barra superior con contador "X de Y" y barra sutil de avance.
- **`RecallInput`**: Textarea para evocación libre con atajo Cmd/Ctrl+Enter y estado de carga.
